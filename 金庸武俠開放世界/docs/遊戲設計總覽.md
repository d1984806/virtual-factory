# 遊戲設計總覽（RPG 概念稿）

本文件將既有的系統規格整合為可實作的「角色扮演遊戲」設計輪廓，作為專案規劃與內容製作的主軸，並補充落地順序與最小可玩範圍。

## 1. 遊戲核心願景
- **類型**：開放世界單人 RPG
- **世界觀**：金庸十四本小說交錯並存，主角可在同一世界中遇見跨書角色。
- **玩家定位**：一名初入江湖的俠客，隨選身世與門派，走向自己的武俠傳奇。

## 2. 核心循環（Core Loop）
1. **探索**：進入城鎮/門派/野外，接觸事件或人物。
2. **對話互動**：建立人物關係、接受任務、取得線索。
3. **戰鬥與成長**：完成戰鬥，獲得物品或武學。
4. **角色養成**：提升屬性、開通經脈、解鎖天賦。
5. **劇情推進**：完成任務推進劇情進度與世界變化。

## 3. 角色系統（人物建立＋天賦＋屬性）
- **人物建立**：玩家選擇名字、身世、門派，決定起始武學與人際關係。
- **天賦**：角色在創建時抽取/選擇 1～2 個天賦（例如：內功悟性、輕功身法）。
- **屬性**：基礎能力（體魄、內力、敏捷、悟性等），影響戰鬥與技能成長。

### 最小可行角色建立（MVP）
- **必填欄位**：姓名、出身（平民/門派/世家）、初始武器偏好。
- **初始天賦池**（5 選 1）：悟性高、根骨佳、身法快、醫術通、善交際。
- **屬性配點**：總點數固定（例如 10 點）自由分配。

## 4. 武學與經脈
- **武學類型**：掌法、劍法、刀法、暗器、內功等。
- **經脈系統**：以「打通穴位」方式提升技能上限、解鎖進階招式。
- **實作建議**：武學與經脈互相綁定，提升經脈可解鎖武學層級。

### MVP 實作方式
- **武學數量**：每類型 1 本入門武學（共 5 本）。
- **經脈節點**：只做 1 條主經脈（3 節點），節點提升武學等級上限。

## 5. 物品與經濟
- **物品類別**：武器、防具、藥品、典籍、任務道具。
- **物品用途**：裝備影響屬性、典籍學習武學、任務道具推進劇情。

### MVP 物品清單
- 武器：木劍、短刀
- 防具：布衣、皮甲
- 藥品：小還丹（回復內力）、止血散（回復體力）
- 典籍：入門內功
- 任務道具：信件/密令（推進任務）

## 6. 任務與劇情進度
- **任務結構**：主線任務 + 支線任務 + 隨機事件。
- **劇情進度**：每條小說劇情被拆成多段主線，玩家自由選擇參與程度。
- **動態世界**：不同任務完成會影響人物關係與世界勢力平衡。

### MVP 任務結構
- 主線 1 條（對應初始城鎮事件）
- 支線 2 條（幫助 NPC、搜集物品）
- 隨機事件 1 條（路遇惡徒/救人）

## 7. 人物關係
- **關係維度**：師徒、同盟、敵對、戀慕、尊敬。
- **影響內容**：解鎖武學、獲取特殊任務、改變劇情走向。

### MVP 關係設計
- 初始固定 3 位關係 NPC（師父、同門、敵對勢力）
- 關係值區間（-100 ～ +100），影響對話與任務開放

## 8. UI 與玩家體驗
- **開頭 UI**：進入世界觀，提供「開始／繼續／設定」與背景故事引導。
- **遊戲內 UI**：顯示角色狀態、任務追蹤、快捷欄與小地圖。

## 9. 範例：最短可玩主線（MVP）
1. 玩家創建角色（選擇門派與天賦）
2. 進入初始城鎮，獲得第一任務
3. 完成簡易戰鬥（獲得物品）
4. 打通第一條經脈，學會武學
5. 推進劇情並開啟第二條主線

## 10. 世界地圖設計（大地圖/城鎮/門派/特殊地點）
- **大地圖**：以區域劃分（中原/西域/江南等），每區配置主要城鎮與門派。
- **城鎮**：提供任務樞紐、商店、情報與住宿，至少一個初始城鎮可承接主線與支線。
- **門派**：作為武學學習與關係成長核心地點，設置拜師與試煉流程。
- **特殊地點**：如古墓、禁地、秘境，用於高階武學與劇情轉折。

### MVP 地點配置
- 1 張大地圖（3 個區域）
- 2 座城鎮（初始城鎮 + 關鍵城鎮）
- 1 個門派（玩家起始門派）
- 2 個特殊地點（主線關卡 + 秘境）

## 11. 開發落地順序（建議）
1. **資料結構定義**：角色、武學、物品、任務。
2. **最小互動流程**：開頭 UI → 人物建立 → 進入城鎮。
3. **最小戰鬥流程**：1v1 戰鬥，結算經驗與掉落。
4. **任務系統**：接受 → 完成 → 推進劇情。
5. **關係系統**：關係值影響對話與任務。

## 12. 後續可擴充方向
- 多主角視角（重玩性）
- 動態世界事件（派系戰爭）
- 武學相剋系統與內功心法樹
