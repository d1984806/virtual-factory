# MVP 原型計畫（第 1 版）

本文件將「請直接開始做 MVP 原型」落成可執行清單，對應目前的遊戲設計總覽內容，提供最小可玩版本的範圍、流程與交付物。

## 1. MVP 目標
- **目標**：可從開頭 UI 進入遊戲，建立角色，進入城鎮，接受任務，完成一場戰鬥並獲得成長回饋。
- **完成判定**：玩家完成初始城鎮主線任務並看到劇情進度前進提示。

## 2. MVP 範圍
### 2.1 系統範圍
- 角色建立（姓名/出身/初始武器偏好 + 天賦 5 選 1 + 屬性配點）
- 任務系統（主線 1、支線 2、隨機事件 1）
- 戰鬥系統（1v1，勝利後結算經驗與掉落）
- 物品系統（武器、防具、藥品、典籍、任務道具）
- 經脈系統（1 條主經脈，3 節點）
- 關係系統（3 位初始 NPC，關係值影響任務開放）
- 世界地圖（3 區域、2 城鎮、1 門派、2 特殊地點）

### 2.2 內容範圍
- 起始城鎮 1 座（主線事件 + 支線）
- 起始門派 1 個（拜師/試煉入口）
- 主線關卡特殊地點 1 個
- 秘境 1 個（藏武學/寶物）

## 3. MVP 玩家流程（可玩最短路徑）
1. 開頭 UI → 選擇「開始」  
2. 角色建立 → 選擇天賦、屬性配點  
3. 進入初始城鎮 → 接受主線任務  
4. 完成戰鬥（1v1） → 獲得物品  
5. 打通第一條經脈 → 解鎖武學等級  
6. 回報任務 → 劇情進度前進  

## 4. 交付物清單（第一版）
### 4.1 文件與資料
- 角色建立表單欄位定義
- 初始天賦清單（5 項）
- 初始物品清單（武器/防具/藥品/典籍/任務道具）
- 任務清單（主線 1、支線 2、隨機 1）
- NPC 關係清單（3 位）
- 地圖節點清單（區域、城鎮、門派、特殊地點）

### 4.2 流程與介面
- 開頭 UI wireframe（開始/繼續/設定）
- 角色建立流程圖
- 遊戲內 HUD 概念草圖（狀態列/任務追蹤/快捷欄）

## 5. 下一步實作順序（可排期）
1. 建立專案引擎（建議：Godot），建立最小場景與 UI 架構
2. 建立資料格式（JSON/CSV）與基礎資料
3. 角色建立流程（UI + 資料寫入）
4. 城鎮場景（NPC 互動 + 任務接取）
5. 戰鬥流程（1v1 + 結算）
6. 經脈與武學解鎖（升級回饋）
7. 劇情進度推進提示

## 7. 進度檢查點
- ✅ 角色建立完成並可保存
- ✅ 城鎮可自由移動與對話
- ✅ 完成一場戰鬥並有掉落
- ✅ 任務完成時有劇情進度提示
